# Contextia

基于文章精读积累生词和语法的工具。不做刷题，只做"划词/划句 → AI 解释 → 长期存档"。

## 当前功能

- 粘贴文本 / 上传 PDF 或 DOCX / **输入网址自动抓取正文**(点"添加文章"里的"网址导入"标签，对 BBC、The Guardian 等新闻网站支持较好，会自动跳过导航栏、广告、推荐阅读等噪音)。PDF/DOCX 上传后台会直接提取正文，跟粘贴文本、网址导入用同一套阅读界面，样式统一；扫描版 PDF(没有文字层，纯图片)提取不出内容会提示失败
- 划中一个**单词** → 弹出"记录生词"按钮 → 调用你在设置里配置的 AI 服务商生成释义/音标/词性 → 存入数据库(主账号还会同步到 Google Sheet「生词」表)
- 划中一句/一段**句子** → 弹出"AI 解析句子"按钮 → 调用 AI 做语法/语义解析 → 存入数据库(主账号还会同步到 Google Sheet「句子笔记」表)
- 右侧「历史记录」侧栏只显示**当前打开这篇文章**保存过的生词/句子笔记（按 `source_doc` 过滤），切换文章、刷新页面或重新打开都会自动对应到那篇文章，不会跟别的文章混在一起
- **「AI 推荐」**：自动拉取新闻标题，交给 AI 按"难度匹配、话题不重复"筛出几篇，每篇带话题标签和难度标注。出于版权考虑，点"读这篇"**不会**把正文抓进站内——只是跳转到源网站的原文页面，同时自动打开"粘贴文本"面板并预填好标题，提示你把正文复制回来粘贴，继续用完整的划词解析功能（母语新闻的"一键沉浸阅读"不受影响，那个功能必须在站内持有正文才能替换词，暂时保留现状）。难度按 CEFR 分级（A1-C2），每个用户按"学习语言"分别设置自己的真实水平（在「AI 推荐」面板里的下拉框选，存在 `user_language_level` 表，不是写死的），改了水平会立刻按新水平重新生成推荐、不会命中旧缓存。结果默认缓存 3 小时，不用每次都重新调用；想换一批就点"换一批"
- **「母语新闻」**：按账号的界面语言（`ui_language`）自动抓对应语言的新闻，用来配合沉浸模式当母语素材，不需要额外配置、不调用 AI（母语内容不需要 AI 判断难度）。点"读这篇"会直接导入文章并自动打开沉浸模式
- **沉浸模式**：打开一篇你能流畅阅读的语言写的文章后，可以在阅读设置里开启，把其中一部分内容按可调节的比例替换成目标学习语言的词/短语，达到"沉浸式"学习的效果；替换比例、要不要排除专有名词都能调
- **间隔重复复习**：简化版莱特纳盒子（Leitner box），标"认识"间隔变长、标"不认识"打回第一级；复习卡片正面是词，翻面看释义/音标/词性/例句，支持发音朗读（`Web Speech API`，浏览器不支持的话按钮自动隐藏）
- **生词/句子笔记可以直接改**：生词本、历史记录里每条记录旁边都有「编辑」按钮——生词能改单词本身、释义、例句、其他形态；句子笔记能改句子原文和解析内容，AI 解析得不准或者想自己补充笔记都不用删了重存
- **打卡连续天数 + 个人学习统计**：顶栏有个"连续 N 天"的小徽章，点开"学习统计"面板能看到近 7 天活跃情况、累计生词/文章数、近 14 天复习正确率趋势
- **全文朗读**：文章详情页可以让浏览器把整篇文章念出来（同样基于 `Web Speech API`）
- 划词提取"所在例句"时会识别常见缩写词（Mr. / U.S. / etc. 等）和小数点，不会在缩写处误断句
- 文章正文里，已经存过的生词会自动加绿色下划线高亮，一眼看出哪些是学过的词
- 存生词时会先查重（不区分大小写），同一个词已经存过会提示"已存过"，不会在 Sheet 里堆出重复行
- 阅读区改版：文章顶部显示标题、来源链接（网址导入的文章可以点回原网站）、预计阅读时长和字数；顶栏右上角的「Aa」按钮可以调字号（小/中/大/特大）、正文宽度（窄/中/宽）、字体（无衬线/衬线），偏好会记在浏览器本地，下次打开自动生效；顶部有一条细的阅读进度条，滚动文章时实时显示读到哪了
- 划词/划句解析失败（网络问题、AI 接口报错等）会显示"重试"按钮，不用重新划一遍
- 顶栏标题旁边显示"本月已调用 N 次"，粗略统计 AI 调用次数
- 顶栏「生词本」按钮：打开后默认显示**全部**生词/句子笔记（不受当前打开哪篇文章限制），也可以在里面继续输入关键词过滤，点结果能直接跳转到对应文章；顶部工具栏能把当前搜索结果**导出成 CSV**（可以导入 Excel/Anki 等工具），也能点「Select」进入批量选择模式，勾选多条后一次性批量删除
- 生词本、当前文章的历史记录里，每条记录右下角都有「删除」按钮，存错的生词/句子笔记可以直接删掉；已同步过 Google Sheet 的记录，本地删除后 **Sheet 里对应的那一行不会自动跟着删掉**（Sheet 表没有唯一 ID 可以精确匹配删除的那一行），需要的话去 Sheet 里手动删
- 文章正文里点一下已经高亮的生词（绿色下划线那种），会弹出当时存的释义/音标/词性/例句，不用再去生词本里翻；弹窗里也能直接删除这个生词
- **多人账号**：支持给几个朋友一起用同一份部署，自己注册用户名密码就能进（没有任何格式限制），也可以用 Google 账号一键登录；每个人的文章/生词/句子笔记互相看不到对方的（细节见下面「多人使用」一节）
- **AI 服务商可选、自己填 key**：顶栏右上角的设置按钮进设置，能选 DeepSeek / OpenAI / Claude / Gemini 中的一个，每个人在自己账号下填自己的 key，谁的 key 谁付费，跟别人无关；填进去的 key 在数据库里是**加密存储**的，不是明文
- **新用户免费试用额度**：如果站长配置了公共体验 key（`HOUSE_AI_API_KEY`），新注册的账号不用先填自己的 key 也能先体验 10 次 AI 解析，用完了再提示自己去设置里填 key；没配置这个的话新用户必须自己填 key 才能用 AI 功能
- **数据库**：账号、文章、生词、句子笔记都存在 Postgres 里（不再是本地 JSON 文件），支持部署到 Railway / Supabase 这类托管平台
- **安全加固**：注册/登录/改密码等接口有访问频率限制，防止被刷；可选接入 Cloudflare Turnstile 人机验证（不配置的话默认跳过，见下文）
- **界面多语言**：顶栏能切换英文/中文/韩文界面（默认英文，定位是通用语言学习平台，不是只给学英语的工具）；第一次打开会弹一个语言选择器，选一次之后记住，不会每次都弹；"学习语言"跟"界面语言"是分开的两个概念——文章和生词可以是英/日/韩/法/西/德/意/葡/俄/阿拉伯/泰语等 12 种语言中的任意一种，会自动根据文字识别，AI 解释用的语言也能单独设置（跟随界面语言，或固定用中文/英文）
- 设置里能修改密码、改用户名；用 Google 登录建的账号本来没有密码，这里显示的是"设置密码"，设置完之后这个账号也能用用户名密码登录了
- 新用户第一次进阅读器主界面，导航栏会依次高亮几个图标（AI 推荐/母语新闻/复习/统计/设置）配一句话说明是干什么的，点一次 Skip 或走完就不会再弹（存在浏览器 `localStorage` 里）
- **站长专属统计页面**：只有主账号导航栏能看到「Site Stats」，展示全站总用户/文章/生词数，以及近 14 天每日新增注册、每日活跃用户的柱状图，用来看发布之后有没有真实效果；后端也做了服务端校验，非主账号直接调接口会被拒绝（403）
- **「升级到 Pro」入口**（变现第一阶段，只做验证付费意愿，还没有真实付费功能）：导航栏有个入口，能登记邮箱到等待名单，站长配置了 `STRIPE_SUPPORT_LINK_URL`（Stripe Payment Link）的话还会显示一个完全自愿、不解锁任何功能的支持入口；产品本身依旧完全免费、BYOK 不变

后续阶段计划：照片 OCR 导入。

## 部署到 Railway(推荐,给朋友用的正式部署方式)

1. 把这个仓库连到 [Railway](https://railway.app/)，选 `Dockerfile` 构建方式（仓库根目录已经有写好的 `Dockerfile`）
2. 加一个 Postgres 插件（Railway 自带的，或者用 [Supabase](https://supabase.com/) 之类的外部 Postgres 都行），拿到连接串
3. 参考仓库根目录的 [`.env.example`](.env.example)，在 Railway 项目的环境变量面板里配置：
   - `DATABASE_URL`（必填，上一步拿到的 Postgres 连接串）
   - `ENCRYPTION_KEY`（必填，生成方式见 `.env.example` 里的注释：`python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`）
   - 其余（Google OAuth、Turnstile、Sheets 同步、免费试用额度、Pro 支持链接）都是可选，不配就是对应功能关闭，不影响核心功能
4. 部署完成后，打开网址会先看到落地页，点 "Get Started" 进到 `/app.html` 自己先注册一个账号，会自动成为"主账号"

## 本地开发(可选)

**Windows(PowerShell)：**

```powershell
cd backend
venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

以后不想每次敲命令，直接双击 `backend\start.bat` 就行，会自动开好服务器并打开浏览器。

**Linux / Mac：**

```bash
./backend/start.sh
```

会自动建虚拟环境、装依赖、在 `http://127.0.0.1:8000` 启动服务。

打开浏览器访问 `http://127.0.0.1:8000`，会先看到产品介绍落地页——点 "Get Started" 才会进到 `http://127.0.0.1:8000/app.html`，也就是真正的阅读器，会看到登录框，第一次用点"注册新账号"，用户名密码自己随便定，没有任何格式要求。本地开发同样需要按下面的说明配一个 `backend/.env`（至少要有 `DATABASE_URL` 和 `ENCRYPTION_KEY`，本地可以自己装一个 Postgres，或者用 Docker 起一个临时的）。

## 多人使用(自助注册)

谁都能自己在登录框里点"注册新账号"，用户名密码随便填，每个账号的数据完全独立、互相看不到。**第一个注册的账号自动成为"主账号"**——只有主账号能开 Google Sheets 同步（因为现在只配了一个 Sheet，其他人的生词不该跑进你的表里）。所以自己部署好之后，第一件事就是自己先注册一个账号占住"主账号"的位置。

给朋友用的话，把网址发给对方，让对方自己点"注册新账号"就行，不用你插手。每个人登录后要自己去设置里选服务商、填自己的 API Key(如果站长配了免费试用额度，前 10 次 AI 解析不填 key 也能用)，不填的话划词解析、AI 推荐这些功能用不了。设置面板里主账号能看到"已注册用户"列表，方便知道都有谁在用。

所有账号信息存在 Postgres 数据库里（密码是加盐哈希存的，不是明文；每个人的 AI API Key 用 `ENCRYPTION_KEY` 加密后存储，不是明文）。想删掉一个账号，去设置里用账号自己的"注销账号"功能，或者直接连数据库删对应的行。

> 如果你是从更早的本地 JSON 存储版本升级上来的：程序启动时会自动把 `data/users.json` 等旧数据一次性迁移进 Postgres（包括把明文 AI Key 补上加密），迁移结果会打印在服务器启动日志里，迁移完之后 `data/` 目录就不再使用了。

## 配置 Google 登录(可选)

不配置的话，登录框里"用 Google 登录"这个按钮点了会提示还没配置，不影响用户名密码登录/注册。想开的话：

1. 去 [Google Cloud Console](https://console.cloud.google.com/) 建一个项目(或用现有的)
2. 左侧菜单找到 **API 和服务 → OAuth 同意屏幕**，"用户类型"选**外部**，发布状态保持**测试**就够用(不用走 Google 的应用审核)；**测试用户**这一栏要把每个朋友的 Google 邮箱加进去，不然他们登录会被 Google 拦下
3. **API 和服务 → 凭据 → 创建凭据 → OAuth 客户端 ID**，应用类型选**Web 应用**，"已获授权的重定向 URI"加两条：
   - `http://127.0.0.1:8000/api/auth/google/callback`(本地开发用)
   - `https://<你的线上网址>/api/auth/google/callback`(部署上线之后用，把域名换成实际的)
4. 建好之后会拿到 **客户端 ID** 和 **客户端密钥**，按 `.env.example` 填进 `.env`（本地）或 Railway 的环境变量（线上）：
   ```
   GOOGLE_CLIENT_ID=你的客户端ID
   GOOGLE_CLIENT_SECRET=你的客户端密钥
   ```

用 Google 登录进来的账号，第一次是自动建的（名字用 Google 账号的名字），本来没有密码，可以去设置里补一个，这样以后也能用用户名密码登录，不一定非得每次都走 Google。

## 配置 Turnstile 人机验证(可选)

不配置的话，注册/登录接口默认跳过人机验证，只靠访问频率限制防刷。想开的话：

1. 去 [Cloudflare Turnstile](https://dash.cloudflare.com/?to=/:account/turnstile) 建一个 Widget，绑定你的域名，拿到 **Site Key** 和 **Secret Key**
2. 按 `.env.example` 填进 `TURNSTILE_SITE_KEY` / `TURNSTILE_SECRET_KEY`
3. 本地测试不想申请真账号的话，Cloudflare 官方发布了公开的测试专用密钥，任何域名(包括 `localhost`)都能用：
   - 永远验证通过：Site Key `1x00000000000000000000AA`，Secret Key `1x0000000000000000000000000000000AA`
   - 永远验证失败：Site Key `2x00000000000000000000AB`，Secret Key `2x0000000000000000000000000000000AA`

## 配置 Google Sheets 同步(可选，只有主账号能用，必须手动做这一步)

先自己新建一个 Google Sheet 用来存生词（随便起个名字，比如"英语学习生词本"），然后按下面步骤把它接上，全程只需要复制粘贴，大概 3 分钟：

1. 打开你新建的这个 Google Sheet
2. 顶部菜单点 **扩展程序 → Apps Script**，会打开一个新标签页的代码编辑器
3. 编辑器里默认会有一段 `function myFunction() {}` 的占位代码，**全选删除**
4. 打开本项目里的 [`apps_script/Code.gs`](apps_script/Code.gs) 文件，把里面的全部内容复制，粘贴进 Apps Script 编辑器
5. 把第一行 `var TOKEN = "..."` 里的占位符换成你自己随便打的一串字符（比如去 [随机字符串生成器](https://www.uuidgenerator.net/) 生成一个），这是用来防止陌生人乱写你的表格的密钥，一定要自己换一个，不要用仓库里的占位值
6. 点编辑器左上角的保存图标(或按 `Ctrl+S`)
7. 点右上角蓝色 **部署 → 新建部署**
   - 点齿轮图标选择类型：**Web 应用**
   - 执行身份：**我**
   - 有权访问的用户：**所有人**
   - 点 **部署**，如果出现"未验证应用"的警告页面，点 **高级 → 转至(项目名)(不安全)** 继续（这是正常的，因为是你自己写的脚本，不是第三方应用）
8. 部署完成后会给你一个 **网络应用网址**(一长串 `https://script.google.com/macros/s/.../exec`)，复制它
9. 按 `.env.example` 把这个网址填进 `SHEETS_WEBHOOK_URL`，再把第 5 步里你自己设的那个 token 填进 `SHEETS_TOKEN`（两边要填一样的值）

配好之后，还要用主账号登录网站，去设置里把「同步到 Google Sheet」的开关打开(默认是关的)——做完这两步，以后每次主账号记录生词/句子笔记才会自动同步进 Sheet。朋友账号看不到这个开关，不用管这一步。

## 目录结构

```
backend/          FastAPI 服务 + 多 AI 服务商调用 + PDF/DOCX 解析 + Postgres 存储 + Google Sheets 同步
  start.bat       Windows 本地启动脚本
  start.sh        Linux/Mac 本地启动脚本
frontend/         静态前端，无构建工具
  index.html      产品介绍落地页(纯英文，独立静态页，不接入下面的 i18n 系统)，`/` 默认显示这个
  app.html        阅读器主应用(粘贴文本 / 网址导入 / PDF / DOCX 统一渲染成同一种网页阅读样式，划词/划句交互，登录/注册也在这个页面)，路径是 `/app.html`
  i18n/           app.html 的界面文案(en.json / zh.json / ko.json)，落地页/法律条款页不用这套
  privacy.html    隐私政策(Google OAuth 审核需要)
  terms.html      服务条款
apps_script/      Google Sheets 的 Apps Script 代码，需要手动部署一次(见上文)
DESIGN_GUIDELINES.md  UI 设计约定(比如"禁止用 emoji 当图标")，改前端界面之前先看一眼
.env.example      环境变量模板，复制成 backend/.env(本地) 或填进部署平台的环境变量面板(线上)
Dockerfile        Railway 等平台的容器构建文件
data/             仅在从旧的本地 JSON 存储版本升级时，服务启动时读取一次性迁移到 Postgres，之后不再使用
```
