# 英语阅读学习器

基于文章精读积累生词和语法的工具。不做刷题，只做"划词/划句 → AI 解释 → 长期存档"。

## 当前功能(第1-2阶段)

- 粘贴文本 / 上传 PDF 或 DOCX / **输入网址自动抓取正文**(点"添加文章"里的"网址导入"标签，对 BBC、The Guardian 等新闻网站支持较好，会自动跳过导航栏、广告、推荐阅读等噪音)。PDF/DOCX 上传后台会直接提取正文，跟粘贴文本、网址导入用同一套阅读界面，样式统一；扫描版 PDF(没有文字层，纯图片)提取不出内容会提示失败
- 划中一个**单词** → 弹出"记录生词"按钮 → 调用你在设置里配置的 AI 服务商生成中文释义/音标/词性 → 存入本地(主账号还会同步到 Google Sheet「生词」表)
- 划中一句/一段**句子** → 弹出"AI 解析句子"按钮 → 调用 AI 做语法/语义解析 → 存入本地(主账号还会同步到 Google Sheet「句子笔记」表)
- 生词/句子笔记会先存在本地(`data/vocab.json`、`data/sentence_notes.json`)兜底，Sheet 同步失败也不会丢数据
- 右侧「历史记录」侧栏只显示**当前打开这篇文章**保存过的生词/句子笔记（按 `source_doc` 过滤），切换文章、刷新页面或重新打开都会自动对应到那篇文章，不会跟别的文章混在一起
- **「AI 推荐」**：自动拉取 BBC / Guardian 当天的新闻标题（覆盖时政、科技、商业、文化、科学等多个板块），交给 AI 按"难度适中、话题不重复"筛出 6-8 篇，每篇带话题标签和难度标注，点"读这篇"直接抓正文开始精读。筛选标准是按四级已过、六级480分的水平定的，写死在 `backend/main.py` 的 `USER_LEVEL_DESC` 里，水平变了可以去改这一行。结果会缓存 3 小时，不用每次都重新调用；想换一批就点"换一批"
- 划词提取"所在例句"时会识别常见缩写词（Mr. / U.S. / etc. 等）和小数点，不会在缩写处误断句
- 文章正文里，已经存过的生词会自动加绿色下划线高亮，一眼看出哪些是学过的词
- 存生词时会先查重（不区分大小写），同一个词已经存过会提示"已存过"，不会在 Sheet 里堆出重复行
- 阅读区改版：文章顶部显示标题、来源链接（网址导入的文章可以点回原网站）、预计阅读时长和字数；顶栏右上角的「Aa」按钮可以调字号（小/中/大/特大）、正文宽度（窄/中/宽）、字体（无衬线/衬线），偏好会记在浏览器本地，下次打开自动生效；顶部有一条细的阅读进度条，滚动文章时实时显示读到哪了
- 划词/划句解析失败（网络问题、DeepSeek 接口报错等）会显示"重试"按钮，不用重新划一遍
- 顶栏标题旁边显示"本月已调用 N 次"，粗略统计 DeepSeek 调用次数，数据存在 `data/api_usage.json`，按自然月累计
- 顶栏「生词本」按钮：打开后默认显示**全部**生词/句子笔记（不受当前打开哪篇文章限制），也可以在里面继续输入关键词过滤，点结果能直接跳转到对应文章
- 生词本、当前文章的历史记录里，每条记录右下角都有「删除」按钮，存错的生词/句子笔记可以直接删掉；已同步过 Google Sheet 的记录，本地删除后 **Sheet 里对应的那一行不会自动跟着删掉**（Sheet 表没有唯一 ID 可以精确匹配删除的那一行），需要的话去 Sheet 里手动删
- 文章正文里点一下已经高亮的生词（绿色下划线那种），会弹出当时存的中文释义/音标/词性/例句，不用再去生词本里翻；弹窗里也能直接删除这个生词
- **多人账号**：这个工具现在支持给几个朋友一起用同一份部署，自己注册用户名密码就能进（没有任何格式限制），每个人的文章/生词/句子笔记互相看不到对方的（细节见下面「多人使用」一节）
- **AI 服务商可选、自己填 key**：顶栏右上角齿轮⚙进设置，能选 DeepSeek / OpenAI / Claude / Gemini 中的一个，每个人在自己账号下填自己的 key，谁的 key 谁付费，跟别人无关

后续阶段计划：照片 OCR 导入；把这套东西部署到公网上，让朋友们能直接用网址打开（目前还是本地运行）。

## 首次运行

```powershell
cd "C:\Users\johnh\OneDrive\Desktop\个人事务\08_英语学习\local-reader\backend"
venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

打开浏览器访问 `http://127.0.0.1:8000`，会先看到登录框——第一次用点"注册新账号"，用户名密码自己随便定，没有任何格式要求。

以后不想每次敲命令，直接双击 `backend\start.bat` 就行，会自动开好服务器并打开浏览器。

## 多人使用(自助注册)

谁都能自己在登录框里点"注册新账号"，用户名密码随便填，每个账号的数据完全独立、互相看不到。**第一个注册的账号自动成为"主账号"**——只有主账号能开 Google Sheets 同步（因为现在只配了一个 Sheet，其他人的生词不该跑进你的表里）。所以自己部署好之后，第一件事就是自己先注册一个账号占住"主账号"的位置。

给朋友用的话，把网址发给对方，让对方自己点"注册新账号"就行，不用你插手。每个人登录后要自己去设置(⚙)里选服务商、填自己的 API Key，不填的话划词解析、AI 推荐这些功能用不了。设置面板里主账号能看到"已注册用户"列表，方便知道都有谁在用。

所有账号信息存在 `data/users.json`（密码是加盐哈希存的，不是明文；每个人的 AI API Key 目前是明文存的，没做加密——这是为了"发给几个朋友用"这个规模特意做的简化，`.gitignore` 已经排除这个文件，不会被传到 GitHub）。想删掉一个账号，直接去这个文件里把对应那条记录删掉即可。

> 如果你是从更早的"邀请码"版本升级上来的：程序启动时会自动把老账号迁移成用户名/密码——用户名是账号名字去掉空格和符号，初始密码就是原来的邀请码，迁移结果会打印在服务器启动日志里。

## 配置 Google Sheets 同步(可选，只有主账号能用，必须手动做这一步)

生词表已经建好：https://docs.google.com/spreadsheets/d/1lLwo0zLczKAV8JGiT6tgoEAookeqbO7akYviL8OrfTg/edit

按下面步骤把它接上，全程只需要复制粘贴，大概 3 分钟：

1. 打开上面这个 Google Sheet
2. 顶部菜单点 **扩展程序 → Apps Script**，会打开一个新标签页的代码编辑器
3. 编辑器里默认会有一段 `function myFunction() {}` 的占位代码，**全选删除**
4. 打开本项目里的 [`apps_script/Code.gs`](apps_script/Code.gs) 文件，把里面的全部内容复制，粘贴进 Apps Script 编辑器
5. 点编辑器左上角的保存图标(或按 `Ctrl+S`)
6. 点右上角蓝色 **部署 → 新建部署**
   - 点齿轮图标选择类型：**Web 应用**
   - 执行身份：**我**



权访问**，选择你自己的 Google 账号，如果出现"未验证应用"的警告页面，点 **高级 → 转至(项目名)(不安全)** 继续（这是正常的，因为是你自己写的脚本，不是第三方应用）
7. 部署完成后会给你一个 **网络应用网址**(一长串 `https://script.google.com/macros/s/.../exec`)，复制它
8. 打开 `backend\.env`(就在这个项目文件夹里)，把这个网址粘贴到 `SHEETS_WEBHOOK_URL=` 后面
9. 保存 `.env`，重启一下 `start.bat`(如果服务器正开着，关掉重开)

配好 `.env` 之后，还要用主账号登录网站，去设置(⚙)里把「同步到 Google Sheet」的开关打开(默认是关的)——做完这两步，以后每次主账号记录生词/句子笔记才会自动同步进 Sheet。朋友账号看不到这个开关，不用管这一步。

`SHEETS_TOKEN` 这个值不用改，`.env` 和 `apps_script/Code.gs` 里已经帮你对好了，是用来防止陌生人乱写你的表格的密钥。

## 目录结构

```
backend/        FastAPI 服务 + 多 AI 服务商调用 + PDF/DOCX 解析 + 本地 JSON 存储 + Google Sheets 同步
frontend/       阅读界面(粘贴文本 / 网址导入 / PDF / DOCX 统一渲染成同一种网页阅读样式)，划词/划句交互
apps_script/    Google Sheets 的 Apps Script 代码，需要手动部署一次(见上文)
data/           documents.json / vocab.json / sentence_notes.json / users.json 是本地数据(不再保留上传文件原件，上传时直接提取文字后就丢弃)
```
