隐私政策

最后更新：2026-07-22

英语阅读学习器（下称"本工具"）是一个个人开发、非商业性质的英语阅读辅助小工具，目前主要供开发者本人及身边朋友使用。本页说明我们收集哪些数据、怎么用、以及你能做什么。

我们收集什么数据

  • 账号信息：用户名和密码（密码经过加密处理后存储，我们本身也看不到明文），或者你用 Google 登录时的账号 ID 和邮箱
  • 你自己填写的 AI 服务商 API Key（加密存储）
  • 你上传/粘贴/导入的文章内容，以及你保存的生词、句子笔记
  • AI 功能的调用次数和估算花销，用于给你自己看用量

数据怎么用

  • 你选中单词或句子请求解析时，对应的文本会被发送给你自己在设置里选择、并填写了 Key 的 AI 服务商（DeepSeek / OpenAI / Claude / Gemini 之一），用来生成解释内容。这是唯一会把你的内容发给第三方的场景。
  • 如果你是主账号并且开启了 Google Sheets 同步，保存的生词/笔记会额外同步一份到你自己配置的 Google 表格。
  • 除上述两种情况外，你的数据不会被分享给任何其他第三方，也不会被用于广告或其他与本工具无关的用途。

数据存储与安全

  • 账号密码使用加盐哈希存储，AI Key 使用加密方式存储，均不是明文
  • 数据存储在 Supabase 提供的 Postgres 数据库中
  • 登录状态（session）30 天后自动失效，需要重新登录

你的权利

  • 你可以随时在设置里修改用户名、密码
  • 你可以联系我们要求删除账号和相关数据，或导出你自己的数据
  • 本工具目前主要面向开发者本人及朋友使用，不会主动索取超出功能所需的信息

条款可能的变化

本工具目前免费提供，未来可能会调整功能范围或引入付费能力，我们不承诺服务永久免费。如条款有重大变更，会在本页面更新并尽量提前告知使用者。
